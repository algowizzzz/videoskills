# Installing the Mac prototype

This is a source and model transport workflow, not a one-command production installer. Use an Apple Silicon Mac with Python 3.11, Git LFS, and FFmpeg/ffprobe installed. Plan for at least 20 GB free during setup; Git LFS chunks, original weights, assembly, Python packages, and caches can coexist temporarily. 32 GB or more unified memory is a practical target for routine use. The original 16 GB Mac worked slowly under memory pressure.

1. Clone the repository with LFS smudging disabled: `GIT_LFS_SKIP_SMUDGE=1 git clone https://github.com/algowizzzz/videoskills.git`. If the LFS transport manifest is absent, there are no published model chunks to pull yet.
2. Run `bash scripts/bootstrap-source.sh` to clone the pinned MuseTalk Mac source and apply the retained local fixes. This requires a network connection during setup. In a truly air-gapped deployment, transfer the prepared source tree instead.
3. Create two Python 3.11 virtual environments: `.venv` for voice and `.venv-video` for video/transcription. Install the matching packages from `requirements-mac.lock.txt` and `requirements-video.lock.txt`. These lockfiles record the tested Mac installation; package and wheel availability must be checked for the target system. An offline target requires a separately prepared wheelhouse.
4. Obtain every required model file listed by `python3 scripts/model_manager.py plan` from its pinned upstream source, or obtain a verified LFS model bundle. Put them at their manifest paths. Never substitute a model revision without updating and verifying its size and hash.
5. If model chunks have been published, run `git lfs pull --include="model-store/**" --exclude=""`, then `python3 scripts/model_manager.py verify-transport` and `python3 scripts/model_manager.py restore`. Run `python3 scripts/model_manager.py verify-installed` before inference. If using direct upstream downloads, skip the chunk commands and run `verify-installed`.
6. Run `./run-local.sh doctor`. For a short clip, use `./run-local.sh voice --reference /absolute/reference.wav --transcript 'exact reference words' --text 'new script' --output outputs/voice.wav`, then `./run-local.sh video --presenter /absolute/presenter.mp4 --audio outputs/voice.wav --float16 --output outputs/presenter.mp4`. If you already have speech audio, run only the video command.

The runtime launcher denies network access to inference on macOS. Missing environments or models should fail; generation never installs them automatically. The wrapper limits audio to 30 seconds. Voice similarity and visual lip sync need human review.
